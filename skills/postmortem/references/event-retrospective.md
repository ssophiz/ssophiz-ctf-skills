# Private event retrospective

## Event record

- Event name and date
- Team and final rank
- Rules and authorization boundary
- Competition duration and infrastructure notes

## Result reconciliation

For each challenge, record category, status, submit result, solver or PoC path, decisive evidence, and write-up page. Use `solved`, `partial`, `unsolved`, or `not attempted`. Note discrepancies instead of silently choosing one source.

## What worked

Identify repeatable technical methods, effective tool combinations, useful division of labor, and evidence that shortened verification.

## What slowed the team

Separate technical blockers, infrastructure outages, worker-credit or liveness failures, duplicate work, missing tooling, and report friction. Connect each problem to a concrete process or skill change.

## Unsolved backlog

Preserve the strongest hypothesis, tested dead ends, relevant artifacts, and the next experiment. Remove any live action that is no longer authorized when the event ends.

## Follow-up

List skill edits, tool setup, regression fixtures, practice tasks, documentation, and owners. Keep secrets in the private vault or credential store, never in the public repository.
