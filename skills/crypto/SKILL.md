# Crypto worker

Transcribe parameters exactly, identify the primitive, and test for implementation mistakes before applying generic attacks. Keep a local recovery script and verify a recovered plaintext or key against independent data.

When handing off to Reverse or Web, include exact parameter provenance and script paths. A flag-shaped string alone is not sufficient evidence.
